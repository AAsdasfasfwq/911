# 9/11 — процедурный 3D-документальный фильм (Three.js + Web Audio)

Видео целиком генерируется кодом: 3D-сцены (Нью-Йорк, башни ВТЦ, самолёты, люди, Пентагон,
Афганистан, Ирак, мемориал и т.д.), инфографика в стиле «editorial montage», титры глав на чёрном
фоне и вся звуковая партитура (эффекты, атмосферы, музыка) — синтезируются в браузере.
Каждая монтажная склейка привязана к словам диктора из `assets/scenario.json`
(Whisper, пословные тайминги), поэтому картинка идёт строго в такт озвучке.

- 16:9, 1920×1080, 30 fps, ~17:43
- без субтитров; текст только в титрах глав («10 лет до», «1 год до», …) и в инфографике
- звук: Web Audio (оффлайн-рендер кусками), диктор `assets/voiceover.mp3`, итоговый микс нормализуется к −16 LUFS

## Установка

```bash
npm install            # ставит Puppeteer (вместе с Chromium)
```

Нужен `ffmpeg` в PATH (или переменная `FFMPEG=/путь/к/ffmpeg`).

## Просмотр в браузере

```bash
npm run preview        # http://localhost:8911
```

Клик — включить звук. Пробел — пауза, ←/→ — ±5 с (Shift — ±30 с), `,` / `.` — покадрово.
`?t=600` — начать с 10-й минуты, `?debug=1` — показать имя текущего плана.

## Рендер видео (Puppeteer, 30 fps)

```bash
node render.js                       # всё видео -> out/911.mp4
node render.js --from 600 --to 660   # только фрагмент (секунды)
node render.js --preview             # быстрый черновик 960x540 без motion blur
node render.js --workers 2           # 2 вкладки параллельно (мощный GPU / много ядер)
node render.js --swiftshader         # программный WebGL (сервер без видеокарты, медленно)
```

Что происходит:
1. Звуковой дизайн рендерится в `out/sfx.wav` (OfflineAudioContext, детерминированно).
2. Каждый кадр выставляется через `window.seekTo(ms)` (с субкадровым motion blur) и снимается
   через CDP; кадры кодируются ffmpeg в 10-секундные сегменты `out/segments_*/seg_*.mp4`.
   Рендер можно прервать и запустить снова — готовые сегменты пропускаются.
3. Сегменты склеиваются, диктор + звук сводятся (двухпроходный loudnorm) → `out/911.mp4`
   (H.264 High, CRF 16, AAC 320k, faststart — готово для YouTube).

Полезные опции: `--crf 16`, `--quality 95` (JPEG кадров), `--mb 2` (субкадры motion blur),
`--sfx 0.5` (громкость звука под голосом), `--voice 1.0`, `--lufs -16`, `--redo-audio`, `--no-audio`.
`CHROME_PATH=/путь/к/chrome node render.js` — использовать установленный Chrome (обычно быстрее GPU).

## Устройство

```
index.html            точка входа (importmap -> vendor/three)
src/main.js           загрузка, сборка фильма, seekTo/totalDuration, превью
src/core/             пайплайн (HDR, MSAA, bloom, DOF, motion blur, грейдинг, переходы),
                      таймлайн/планы, привязка к словам сценария, камеры, 2D-оверлей
src/assets/           процедурные модели и текстуры (город, ВТЦ, самолёты, люди, техника …)
src/sets/             локации (Манхэттен, инфо-студия, глобус, интерьеры, Ближний Восток, США …)
src/shots/ch*.js      монтажный лист по главам (каждый план — фраза диктора)
src/audio/            синтез звука: sfx.js (эффекты), beds.js (атмосферы и музыка), engine.js
render.js             экспорт через Puppeteer + ffmpeg
```
